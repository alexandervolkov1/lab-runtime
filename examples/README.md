# Configuration examples

Start without hardware using [runtime.minimal.toml](runtime.minimal.toml) or
[runtime.virtual.toml](runtime.virtual.toml). See the
[configuration guide](../docs/configuration.md) for setup and recording paths.

[simple-device/](simple-device/) contains developer-oriented read-only and writable
protocol examples. Review the port, device definition and output safety settings
before adapting them to real equipment; they are not ready-to-run hardware setups.

Historical Metakon configurations are internal
[regression fixtures](../test-data/fixtures/metakon/README.md), not user examples.
