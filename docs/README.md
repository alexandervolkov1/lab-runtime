# User manual

Use these guides with the downloaded Runtime and Workbench packages. You do not
need a compiler, a source checkout or a programming language.

## Start here

1. [Your first experiment](getting-started.md) — Windows installation, a virtual
   instrument, a live plot, a setpoint change, recording and shutdown.
2. [Workbench guide](workbench.md) — everyday viewing and operator controls.
3. [Recording](recording.md) — start/stop results, file locations and backups.

## Set up your laboratory

- [Configuration](configuration.md) — virtual setup and a read-only serial device.
- [Linux Runtime](linux-runtime.md) — download, start and stop without a desktop.
- [Two computers](distributed-workbench.md) — Linux Runtime and Windows Workbench
  on a trusted local network.
- [Troubleshooting](troubleshooting.md) — startup, connection and recording errors.

Start with virtual instruments. Closing Workbench does not stop Runtime or make
physical equipment safe. If a command's result is uncertain, do not repeat it
blindly.
