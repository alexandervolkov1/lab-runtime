Статус: migration analysis, 2026-09-14. Это описание существующего поведения, не разрешение на implementation и не новая редакция архитектуры.

## Baseline и границы достоверности

Изучен `D:\rust\com_port_reader`, ветка `feature/rust-core-api`, commit `50d3d1e3de84c650e1aa0ffbf1625044f794d315` (`feat: share runtime between GUI and JSON server`). Working tree на начало анализа чистый. Cargo package имеет version `0.1.0`, но HEAD находится на 34 commits после тега `v0.1.0`: это development snapshot, не содержимое tagged release. Далее «v1» означает именно этот snapshot.

Метод: чтение реализации, colocated unit tests, integration tests, Lua bindings, моделей, профилей и документации. Cargo/tests, GUI, серверы, Lua и физический I/O в ходе анализа не запускались. «Есть» означает наличие реализованного пути и проверенной по тексту тестовой спецификации, а не свежий successful test run или hardware acceptance.

Полностью прочитаны AGENTS.md, PROJECT_BRIEF.md, ARCHITECTURE_PLAN.md, пять текущих architecture-документов, три ADR и MIGRATION_ANALYSIS_PLAN.md. Target baseline — [HIGH_LEVEL_ARCHITECTURE](../architecture/HIGH_LEVEL_ARCHITECTURE.md), [EXTENSION_MODEL](../architecture/EXTENSION_MODEL.md), [RUNTIME_AND_SAFETY_MODEL](../architecture/RUNTIME_AND_SAFETY_MODEL.md). Статусы существующих Proposed ADR не изменены.

README и старые overview недостаточны: текущий HEAD уже содержит отдельные `CoreHost` и JSON server; GUI pumping перенесён на host thread. При этом bounded recorder observer не означает bounded SQLite writer queue. Утверждения ниже сверены с кодом. [BABASHKA_HANDOFF](../../../com_port_reader/docs/BABASHKA_HANDOFF.md) описывает промежуточную Phase B и сам не является release acceptance.

Ссылки на donor предполагают sibling checkout `rust/com_port_reader`; символы относятся к зафиксированному выше commit. ## Финальная проверка этапа

Созданы все семь migration deliverables: 38 feature entries, 48 component groups, target-first mapping, reuse plan с 16 test groups, 22 risks, отдельный architecture feedback и предложенный nine-stage POC. Проверены 281 local link target и существование всех 79 явно названных function/test references в test matrix. Обычный `git diff --check` проходит; семь новых untracked migration files отдельно проверены через `git diff --no-index --check`.

В AGENTS.md/PROJECT_BRIEF.md исправлены только очевидные naming leftovers этой задачи; прежние пользовательские изменения сохранены. `stateDiagram-v2` — синтаксис Mermaid, не старое имя проекта, оставлен без изменений. Исходные architecture/ADR/POC docs, MIGRATION_ANALYSIS_PLAN.md и пользовательский all.txt не переписывались. Commits не создавались.

Финальный HEAD/clean status donor совпадают с baseline; повторный SHA-256 manifest всех 181 tracked files совпал побайтно с начальным. Production/implementation files в lab-runtime не созданы. Tests/builds/hardware не запускались; verification данного этапа — static analysis и проверки документации. Дальше нужна отдельная команда на implementation, автоматического продолжения переноса нет.
